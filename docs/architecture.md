# Архитектура

## Схема

| Уровень | Компонент | Адрес/порт |
|---|---|---|
| Сеть | Локальная сеть | `<SUBNET>/24` (например, `192.168.2.0/24`) |
| Хост | Hyper-V VM (Debian 12) | `<SERVER_IP>` (например, `192.168.2.111`), 6 GB RAM, 2 CPU, 100 GB |
| Docker | Nextcloud | :80 |
| Docker | ONLYOFFICE | :8080 |
| Docker | MariaDB | внутренняя, без порта наружу |
| Docker | Snipe-IT | :8082 |
| Docker | BookStack | :8088 |
| Docker | Stirling PDF | :8090 |
| Docker | Uptime Kuma | :8086 |
| Docker | Homarr | :8085 |
| Docker | Portainer | :9000 |

## Принципы

- **Изоляция.** Нет выхода в интернет, нет проброса портов.
- **Стабильность.** Версии образов зафиксированы.
- **Воспроизводимость.** Всё описано в Docker Compose.
- **Документированность.** Каждый сервис описан в `docs/`.
